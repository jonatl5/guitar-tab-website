NOTES:
------
- The website now uses a Next.js frontend instead of the old static `frontend/index.html`.
- The backend supports both uploaded videos and YouTube URL processing.
- The only required model for core runtime is `backend/models/best.pt`.
- `backend/models/siamese_cnn.pt` is optional at runtime; if missing, duplicate filtering is disabled.
